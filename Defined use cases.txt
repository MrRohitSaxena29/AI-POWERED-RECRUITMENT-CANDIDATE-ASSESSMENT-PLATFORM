Think about who will use the system and what they need to do:	Candidate: Register, upload resume, search/apply for jobs, take assessments, track status.	Recruiter/HR: Create job postings, view applicants, shortlist, schedule interviews, analyze resumes.	Admin: Manage users, companies, audit logs, monitor suspicious activity.Draft User StoriesWrite simple “As a [role], I want to [action] so that [benefit]” statements:	- As a candidate, I want to upload my resume so the system can analyze my skills.	- As a recruiter, I want to see a match score so I can quickly shortlist candidates.	- As an admin, I want to monitor logs so I can detect misuse.System Architecture (High-Level)	- Plan the tech stack:		Frontend: React + TypeScript		Backend: Spring Boot (REST APIs)		Database: PostgreSQL		AI Service: Resume parsing, job matching, interview Q&A		Deployment: Docker + AWSPostgreSQL:-Port: 5432Pass: Bmw@29
